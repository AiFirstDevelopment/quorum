# dist/agensi — Agensi marketplace deliverables

Generated by `tools/agensi/package.py`; nothing here has been uploaded. ZIPs are
git-ignored; listings and reports are plain Markdown.

| Path | What |
|---|---|
| `packages/` | Versioned ZIPs to upload |
| `listings/` | Listing copy, one file per package |
| `reports/` | inventory, compatibility, pricing, submission checklist, and `validation.md` (generated) |

## Regenerate after a Quorum release

    python3 tools/agensi/package.py     # rebuild ZIPs (versions come from plugin.json)
    python3 tools/agensi/validate.py    # re-validate, rewrites reports/validation.md

Update version/price text in `tools/agensi/content/` if a release changes
behavior; the scripts read versions from each `plugin.json`, and fail if the
source skills no longer match what the packager expects. Both scripts need only
Python 3.9+. See `reports/submission-checklist.md` for upload steps.
